# site to APP Converter

A mobile-friendly web application that converts any website into an Android APK file. Works directly in your smartphone browser and can be deployed on GitHub Pages.

## Features
- 🚀 Convert websites to APK in seconds
- 📱 Mobile-optimized interface
- 🆓 Completely free
- 🔒 No data storage
- 📦 Generates complete Android project
- 🎨 Custom app name and package name

## How to Use on Smartphone
1. Open the website on your smartphone browser
2. Enter your website URL
3. Set your app name and package name
4. Click "Generate APK"
5. Download the source code
6. Build with Android Studio or online builder

## Deploy on GitHub Pages
1. Create a new GitHub repository
2. Upload all files from this project
3. Go to Settings → Pages
4. Select "main" branch as source
5. Your site will be live at `https://username.github.io/repository-name`

## How It Works
The converter generates:
- Android WebView app source code
- HTML wrapper for the website
- AndroidManifest.xml
- All necessary configuration files

## Requirements
- Modern smartphone browser (Chrome, Safari, Firefox)
- Internet connection
- For building APK: Android Studio or online APK builder

## Limitations
- Basic WebView functionality only
- No native Android features
- Requires manual APK building
- Works best with responsive websites
